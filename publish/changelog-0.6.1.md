First public release on Modrinth.

- The pack's own mod is now published separately as **Random Item Skyblock Core** and downloaded from Modrinth like every other mod, instead of being bundled inside the pack.
- The server pack no longer needs Python. Run `START-SERVER.cmd` on Windows or `sh start.sh` on Linux and macOS. On first start it asks you to accept the Minecraft EULA, downloads and checks NeoForge and the server mods, and gets a portable Java 21 if Java 21 isn't installed.
- New pack and mod icon.

Gameplay, mods and settings are unchanged from 0.6.0. Worlds from 0.6.0 (and from 0.4.0 onwards) carry over.
